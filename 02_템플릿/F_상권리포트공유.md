# [템플릿 F] 상권 리포트 공유

> 원본: 보유 상권분석 리포트(아티팩트) 1개 → 블로그 글 1편
> 분량: 2,000~3,000자 / 이미지 10~13장 (자동 카드 7~9장 + 현장 사진 2~4장)

## 카드 구성 (기본 순서)

| 순서 | 카드 | type |
|---|---|---|
| 1 | 표지 — 결론 한 문장 + 대표 숫자 | `cover` |
| 2 | 핵심 숫자 4개 | `kpi` |
| 3 | 추이 그래프 | `line` |
| 4~6 | 추천 이유별 근거 (증감 막대 / 표 / 숫자) | `bars` `table` `kpi` |
| 7 | 함께 살펴보실 점 | `list` (warn) |
| 8 | 전체 리포트 받아보기 | `cta` |

> 원칙과 금지사항: `01_전략/상권리포트_시리즈.md`
> 🖼️ 이미지 카드는 자동 생성: 글 폴더에 `원고.md` + `cards.json` → `tools/card_maker/README.md`
> 글 폴더 예시: `04_글감/상권리포트_01_서현역/`

## 본문

### 0. 도입 — 왜 이 자료를 만들었나 (3~4줄)
"○○ 자리를 찾는 손님들께 감이 아니라 숫자로 설명드리려고, 공공데이터로 ○○ 상권을 정리했습니다. 오늘은 그 자료를 공유합니다."

### 1. 핵심 숫자 (리포트 상단 KPI 그대로)
> 📊 **한눈에 보기**
> - 
> - 
> - 
> (기준: ○○○○년 ○분기 / 출처 아래 표기)

{{card:kpi}}

### 2. 결론 한 문장
리포트 제목 문장을 풀어서 2~3줄.

### 3. 소제목 3~5개 = 리포트의 "추천하는 이유" 카드
각 소제목마다:
- 숫자 1~2개
- 그게 무슨 뜻인지 쉬운 말로 1~2줄
- {{card:근거카드}} (bars / table / kpi)

### 4. 함께 살펴보실 점 (불리한 점 2~3개)
리포트의 "함께 살펴보실 점" 그대로. 빼지 말 것.

### 5. 중개사 한 줄 의견 (현장 경험)
"데이터로는 ○○인데, 실제 현장에서 보면…" ← 직접 작성

📷 현장 사진 2~3장

### 6. 전체 리포트 안내 (문의 유도)
```
📊 이 글은 「○○ 리포트」의 요약입니다.
전체 표와 분기별 추이가 담긴 리포트가 필요하시면
문자로 "○○ 리포트"라고 남겨주세요. 링크로 바로 보내드립니다.
```
