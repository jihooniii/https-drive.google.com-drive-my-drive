# [템플릿 B] 상권(동네) 분석

> 분량: 2,000~3,500자 / 사진 10~15장 (직접 걸으면서 촬영)
> 가장 "전문가"로 보이게 해주는 글. 한 번 잘 써두면 오래 검색됩니다.
> 상권 데이터는 소상공인 상권정보 시스템, 실거래가 공개시스템 등을 출처와 함께 인용.

---

## 제목 공식
`[동네] 상권 분석 | [핵심 특징] ([연도] 기준)`

예) `수내역 상권 분석 | 학원가와 직장인 점심 상권이 겹치는 곳 (2026년 기준)`

## 본문

### 0. 도입
"○○동에서 창업이나 사무실을 알아보시는 분들이 꼭 물어보시는 게 있습니다. '여기 장사 돼요?' 오늘 직접 걸으면서 정리해봤습니다."

### 1. 동네 한눈에 보기
- 위치·교통: (지하철역, 버스, 주요 도로)
- 배후 수요: (아파트 단지 ○세대, 오피스 빌딩, 학교)
- 상권 성격: (항아리형 / 통과형 / 오피스 / 주거 밀착)

📷 지도 캡처(직접 표시) 또는 역 출구 사진

### 2. 구역별로 나눠 보기
| 구역 | 특징 | 강한 업종 | 임대료 체감 |
|---|---|---|---|
| ○○역 출구 앞 | | | 높음 |
| 먹자골목 | | | 중간 |
| 아파트 상가 | | | 낮음 |

📷 구역별 거리 사진

### 3. 시간대·요일별 분위기 (현장 관찰)
- 평일 점심: 
- 평일 저녁: 
- 주말: 

> 이 부분이 직접 가본 사람만 쓸 수 있는 내용 → 네이버가 높게 평가하는 "경험 정보"

### 4. 임대 시세 감 (범위로)
- 1층 전용 10평대: 보증금 ○~○천 / 월 ○~○백
- 2층 이상: 
- 공실 체감: (많음/보통/적음, 최근 변화)

> 특정 매물 가격이 아니라 "범위"로. 기준 시점 꼭 표기.

### 5. 이런 창업자에게 맞습니다 / 안 맞습니다

### 6. 중개사 한 줄 의견
"제가 이 동네에서 ○년 중개하면서 느낀 건…"

### 7. 마무리
"○○동 자리 찾고 계시면 업종과 예산만 알려주세요. 공개 안 된 자리도 같이 찾아드립니다."
