# 부동산 네이버 블로그 운영 키트

네이버 블로그에 부동산 글을 **꾸준히, 같은 품질로** 올리기 위한 작업 폴더입니다.
글을 매번 처음부터 고민하지 않도록 "전략 → 템플릿 → 일정 → 체크리스트" 순서로 정리했습니다.

## 폴더 구성

| 폴더 | 내용 | 언제 보나 |
|---|---|---|
| `01_전략/` | 블로그 방향, 카테고리, 키워드 | 처음 한 번 + 분기마다 점검 |
| `02_템플릿/` | 글 종류별 뼈대(복사해서 채우기) | 글 쓸 때마다 |
| `03_운영/` | 발행 일정, 발행 전 체크리스트, 성과 기록 | 매주 |
| `04_글감/` | 쓸 거리 메모, 작성 중인 초안 | 수시로 |
| `05_발행완료/` | 발행한 글 원고 보관 (재활용·수정용) | 발행 직후 |

## ⭐ 간판 시리즈: 상권 리포트 공유

보유한 지역별·업종별·프랜차이즈별 상권분석 리포트를 **주 1편씩** 블로그로 공유합니다.
- 운영 방식: `01_전략/상권리포트_시리즈.md`
- 발행 순서·원본 링크: `03_운영/상권리포트_발행목록.md`
- 템플릿: `02_템플릿/F_상권리포트공유.md`
- 1편 초안(서현역): `04_글감/상권리포트_01_서현역.md`

## 글 한 편 쓰는 순서 (약 40~60분)

1. `03_운영/발행캘린더.md`에서 이번 글 종류 확인
2. `01_전략/키워드.md`에서 키워드 1개 고르기
3. `02_템플릿/`에서 해당 템플릿을 `04_글감/YYYY-MM-DD_제목.md`로 복사
4. 빈칸 채우기 → 사진 직접 촬영분 6~12장 준비
5. `03_운영/발행전_체크리스트.md` 확인 후 네이버에 발행
6. 원고를 `05_발행완료/`로 옮기고 `03_운영/성과기록.md`에 한 줄 기록

> Claude에게 맡기는 방법: "04_글감에 ○○ 주제로 정보형 템플릿 채워줘" 처럼 요청하면
> 초안을 만들어 드립니다. 사진·현장 경험·가격 확인은 직접 해야 합니다.
