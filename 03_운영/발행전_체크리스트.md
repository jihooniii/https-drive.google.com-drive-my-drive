# 발행 전 체크리스트

## ⚖️ 1. 매물 광고 필수 표기 (매물 글은 반드시)

공인중개사법 제18조의2(중개대상물의 표시·광고)와 국토교통부 고시
「중개대상물의 표시·광고 명시사항 세부기준」에 따라 블로그 매물 글도 **인터넷 표시·광고**에 해당합니다.

**중개사무소·중개사 정보**
- [ ] 중개사무소 명칭
- [ ] 소재지
- [ ] 연락처
- [ ] 등록번호
- [ ] 개업공인중개사 성명

**중개대상물 정보 (인터넷 광고 시)**
- [ ] 소재지
- [ ] 면적
- [ ] 가격 (보증금/월세)
- [ ] 중개대상물 종류
- [ ] 거래 형태
- [ ] 건축물 총층수 / 해당층
- [ ] 사용승인일
- [ ] 방향
- [ ] 주차대수
- [ ] 입주 가능일
- [ ] 관리비

**금지 사항 (과태료 대상)**
- [ ] 이미 계약된 매물 → 바로 글 수정/"계약완료" 표시
- [ ] 실제와 다른 가격·면적·사진 사용 금지
- [ ] 중요 단점(하자, 제한사항) 숨기지 않기
- [ ] 의뢰받지 않은 매물 광고 금지
- [ ] 중개보조원 명의로 광고 금지

> 위 항목은 일반적인 정리입니다. 고시가 개정될 수 있으니 분기마다 최신 기준을 확인하세요
> (국가법령정보센터에서 "중개대상물의 표시·광고 명시사항 세부기준" 검색).

## ✍️ 2. 글 품질

- [ ] 제목에 메인 키워드가 앞쪽에 있다
- [ ] 첫 3줄 안에 "이 글이 무슨 내용인지" 나온다
- [ ] 소제목으로 구간이 나뉘어 있다
- [ ] 직접 찍은 사진 6장 이상 (사진 파일명에도 키워드 넣으면 좋음: `정자동상가_외관.jpg`)
- [ ] 숫자·날짜가 구체적이다 ("요즘" ❌ → "2026년 10월 기준" ⭕)
- [ ] 같은 단어를 억지로 반복하지 않았다 (메인 키워드 본문 3~6회 정도)
- [ ] 맞춤법 검사 (네이버 에디터 내장 기능)
- [ ] 모바일 미리보기로 확인 (독자의 70% 이상이 모바일)

## 🔗 3. 연결

- [ ] 글 하단 공통 서명
- [ ] 관련 이전 글 링크 1~2개
- [ ] 태그 10개 내외
- [ ] 매물/상권 글은 네이버 지도 장소 첨부
- [ ] 알맞은 카테고리 선택

## 🔒 4. 개인정보

- [ ] 손님·임대인 이름, 연락처, 계약서 원본 노출 없음
- [ ] 사진 속 사람 얼굴, 차량 번호판 가림
