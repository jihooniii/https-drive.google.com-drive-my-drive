# 블로그 이미지 카드 자동 생성기

글 하나에 들어갈 **이미지 카드(1080px PNG)**를 자동으로 만들고, 원고의 정해진 자리에 끼워 넣어 `발행본.md`를 만들어 줍니다.

## 가장 쉬운 사용법 — Claude에게 말하기

> "상권 리포트 2편(한식 프랜차이즈) 원고랑 카드 만들어줘"

Claude가 `원고.md`와 `cards.json`을 쓰고 카드까지 만들어서 올려둡니다.
숫자나 문구를 고치고 싶으면 "3번 카드 제목 바꿔줘"처럼 말하면 됩니다.

## 글 폴더 구성

```
04_글감/상권리포트_01_서현역/
├ 원고.md       ← 본문. 카드 들어갈 자리에 {{card:카드이름}}
├ cards.json    ← 카드 내용 (숫자·문구)
├ cards/        ← 생성된 이미지 (01_cover.png, 02_kpi.png …)  ※ 자동 생성
└ 발행본.md     ← 카드가 끼워진 완성 원고                     ※ 자동 생성
```

## 직접 실행 (컴퓨터에 Node.js가 있을 때)

```bash
cd tools/card_maker && npm install && npx playwright install chromium   # 처음 한 번
node tools/card_maker/make_cards.mjs 04_글감/상권리포트_01_서현역
```

- 정사각형에 내용이 다 안 들어가면 **자동으로 세로형(1080×1350)**으로 바뀝니다.
- 세로형으로도 넘치면 `⚠️ 내용 넘침`이 뜹니다 → 글자를 줄이세요.

## 카드 종류 (`cards.json`의 `type`)

| type | 용도 | 주요 항목 |
|---|---|---|
| `cover` | 표지 (첫 장, 네이버 대표 이미지) | `eyebrow`, `title`, `subtitle`, `stat{value,label}` |
| `kpi` | 핵심 숫자 2~4개 | `items[{label, value, note, tone}]` |
| `line` | 추이 꺾은선 (최대 3개 계열) | `x`, `series[{name, values}]`, `baseline` |
| `bars` | 업종별 증감 막대 + 비교 눈금 | `items[{label, value, bench, note}]`, `unit`, `benchLabel` |
| `table` | 표 | `columns`, `rows`, `highlight`(강조할 행 번호, 0부터) |
| `list` | 체크포인트 / 함께 살펴보실 점 | `items[{head, text}]`, `tone:"warn"` |
| `cta` | 마지막 문의 유도 | `title`, `body`, `action` |

**문구 꾸미기:** `==파란 강조==`, `**굵게**`, `\n` 줄바꿈
**색:** `tone: "up"`(파랑) / `"down"`(빨강) — 숫자가 `+`면 파랑, `−`면 빨강으로 자동 표시(표)
**출처:** 모든 카드 하단에 `source`가 들어갑니다. 카드별로 다르면 그 카드에 `source`를 따로 적으세요.

## 브랜드 바꾸기

`brand.json`에서 상호, 시리즈 이름, 연락처, 색을 바꾸면 모든 카드에 반영됩니다.
**⚠️ 연락처가 아직 임시값(000-0000)입니다. 실제 번호로 바꿔주세요.**

## 네이버 블로그에 올리는 법

네이버는 블로그 자동 글쓰기 기능(API)을 열어두지 않아서 **마지막 업로드는 직접** 해야 합니다. 대신 5분이면 끝납니다.

1. `발행본.md`를 열어 본문을 네이버 에디터에 붙여넣기
2. 에디터에서 사진 버튼 → `cards/` 폴더의 이미지를 **전체 선택**해서 한 번에 업로드
   (파일 이름이 01, 02 … 순서라 올린 순서대로 정렬됩니다)
3. 각 이미지를 `발행본.md`에서 이미지가 있는 자리로 끌어다 놓기
4. **첫 장(01_cover)을 대표 이미지로 지정** → 검색 결과 썸네일이 됩니다

## 디자인 원칙

- 1080px 정사각형: 모바일에서 꽉 차게 보이고, 인스타그램에도 그대로 쓸 수 있음
- 카드마다 결론 한 문장 제목 + 숫자 강조 + 하단에 출처
- 파랑 = 증가/강조, 빨강 = 감소, 회색 = 비교 기준. 색만으로 구분하지 않도록 모든 숫자에 +/− 표기
- 폰트: Noto Sans KR (SIL Open Font License, `fonts/OFL.txt`)
