# 카테고리 구성

카테고리는 **6개 이하**로 단순하게. 너무 잘게 나누면 빈 카테고리가 생겨 오히려 허전해 보입니다.

```
📌 공지 · 블로그 소개 / 문의 방법
🏢 매물 소개
   ├ 상가 임대
   └ 사무실 임대
📊 상권 리포트  ← 간판 시리즈 (01_전략/상권리포트_시리즈.md)
   ├ 지역편
   ├ 업종편
   └ 프랜차이즈편
📍 분당 동네 탐방
   (현장 사진 위주 가벼운 상권 글 — 정자 / 서현 / 판교 / 수내 / 미금 …)
📚 창업·임대차 가이드
   (계약, 권리금, 세금, 인테리어, 업종 선택)
📈 시장 동향
   (월간 시세, 공실률, 정책 변화)
✍️ 현장 이야기
   (계약 후기, 손님 사례, 중개사 일상)
```

## 카테고리별 "시리즈" 아이디어

시리즈로 묶으면 독자가 다음 편을 찾아보고, 글감 고민도 줄어듭니다.

| 카테고리 | 시리즈명 예시 | 주기 |
|---|---|---|
| 상권 리포트 | `[상권 리포트 #1] 서현역 상권, 경기도 평균보다 덜 빠졌다` | 주 1회 |
| 분당 동네 탐방 | `[동네 탐방] 정자동 카페거리 편` | 월 1~2회 |
| 창업·임대차 가이드 | `[상가 계약 A to Z] 1편: 계약 전 확인할 10가지` | 주 1회 |
| 시장 동향 | `[월간 분당 상가] 2026년 10월` | 월 1회 |
| 현장 이야기 | `[계약 일지] 30평 학원 자리 찾은 이야기` | 월 1~2회 |
