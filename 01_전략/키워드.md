# 키워드 전략

## 원칙

- **큰 키워드는 피한다:** "상가 임대", "부동산"은 경쟁이 너무 심해 신규 블로그는 안 보입니다.
- **지역 + 물건 + 조건** 조합(롱테일)을 노린다: "정자동 1층 상가 임대 20평"
- 글 하나 = 메인 키워드 1개 + 보조 키워드 2~3개

## 키워드 고르는 법 (5분)

1. 네이버 검색창에 메인 단어 입력 → **자동완성/연관검색어** 메모
2. 네이버 검색광고 > 키워드도구(무료 가입)에서 월간 검색량 확인
   - 월 100~2,000회: 신규 블로그가 노리기 좋은 구간
3. 실제 검색해서 1페이지 블로그 글들을 보고 "내가 더 잘 쓸 수 있나?" 판단
