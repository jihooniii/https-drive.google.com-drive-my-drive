# 블로그 전략

## 1. 목표

- **1차 목표:** "분당 상가·사무실 = 이 블로그"로 검색에서 꾸준히 노출 → 전화/문자 문의
- **2차 목표:** 블로그 글 링크를 손님 응대에 재활용 (설명 시간 단축, 신뢰 확보)

> 가정: 분당·경기 지역 상가/사무실 임대 중개가 주력. 다르면 알려주세요.

## 2. 누구를 위해 쓰나 (타깃 독자)

| 독자 | 주로 검색하는 말 | 원하는 것 |
|---|---|---|
| 창업 준비자 | "정자동 상가 임대", "카페 창업 상가 고르는 법" | 입지·권리금·비용 감 잡기 |
| 사무실 이전 담당자 | "판교 사무실 임대", "분당 소형 사무실" | 시세, 관리비, 주차, 입주 일정 |
| 건물주/임대인 | "상가 공실 해결", "임대료 적정선" | 빨리 임차인 맞추기 |
| 투자자 | "분당 상가 매매 수익률" | 수익률, 리스크 |

**글 쓸 때 기준:** 이 중 딱 한 명을 정해서 그 사람에게 말하듯 쓴다.

## 3. 네이버 노출 원리 — 꼭 알아야 할 것만

네이버 블로그 검색은 크게 두 가지로 평가합니다.

- **C-Rank (블로그 신뢰도):** 한 주제를 꾸준히, 오래 쓴 블로그를 믿는다.
  → 부동산 외 잡다한 글 줄이기, 주 2~3회 꾸준히 발행.
- **D.I.A.+ (글 하나의 품질):** 직접 경험·현장 정보가 담긴 글을 높게 친다.
  → 직접 찍은 사진, 실제 현장에서 본 내용, 구체적인 숫자.

### 하면 좋은 것
- 직접 촬영한 사진 (같은 사진 재사용 X, 다른 사이트 사진 X)
- 본문 1,500~3,000자, 소제목으로 구간 나누기
- 제목 앞쪽에 핵심 키워드 1개 자연스럽게
- 글 끝에 관련 이전 글 링크 1~2개 (블로그 안에서 돌게)
- 댓글·문의에 빠르게 답하기

### 피해야 할 것 (노출 떨어짐)
- 같은 키워드를 본문에 억지로 수십 번 반복
- 매물 광고 글만 연달아 올리기 → **정보글과 섞기**
- 다른 블로그/기사 복사·붙여넣기, 거의 같은 글 반복 발행
- 외부 링크(카톡 오픈채팅, 다른 사이트) 남발
- 하루에 몰아서 여러 편, 그 후 몇 주 쉬기

## 4. 콘텐츠 비율

| 종류 | 비율 | 역할 |
|---|---|---|
| 정보형 (계약·세금·창업 팁) | 40% | 검색 유입, 신뢰 |
| 지역·상권 분석 | 30% | "이 지역 전문가" 이미지 |
| 매물 소개 | 20% | 직접 문의 전환 |
| 현장 일기·계약 후기 | 10% | 사람 냄새, 친근함 |

## 5. 블로그 기본 세팅 (한 번만)

- [ ] 블로그명: `분당 상가·사무실 ○○공인중개사` 처럼 지역+분야+상호
- [ ] 프로필: 얼굴 사진, 경력, 사무소 주소, 전화번호, 등록번호
- [ ] 카테고리: `카테고리구성.md` 대로 만들기
- [ ] 상단 공지글: "이 블로그 소개 + 문의 방법" 1편
- [ ] 글 하단 서명(공통 문구): `02_템플릿/공통_서명.md` 내용을 네이버 "글 하단 설정"에 저장
- [ ] 네이버 스마트플레이스(지도)에 사무소 등록 후 블로그 연결

## 6. 참고할 만한 곳

- 네이버 블로그 공식 블로그 / 네이버 서치어드바이저 가이드: 노출 정책 변경 공지
- 네이버 데이터랩, 검색광고 키워드도구: 키워드 검색량 확인 (`키워드.md` 참고)
- 국토교통부 실거래가 공개시스템, 한국부동산원 R-ONE: 시세·통계 인용
- 소상공인시장진흥공단 상권정보 시스템: 상권 분석 글의 업종·유동인구 자료
- 같은 지역 잘되는 중개사 블로그 3곳 정도 골라 **구성만** 참고 (문장 복사 금지)

## 확인 필요 질문 (답 주시면 전체 문서에 반영)

1. 사무소 이름 / 주 활동 동네(예: 정자·서현·판교)는?
2. 주력 물건: 상가·사무실 임대가 맞나요? 아파트·매매도 다루나요?
3. 블로그는 새로 만드나요, 기존 블로그가 있나요? (있으면 주소)
4. 일주일에 몇 편 가능하세요? (기본 주 3편으로 잡았습니다)
5. 말투: 친근한 "~요" 체 vs 전문가 "~습니다" 체?
