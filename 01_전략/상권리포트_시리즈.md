# 상권 리포트 공유 시리즈

이미 만들어 둔 상권분석 리포트(Claude 아티팩트)를 **한 편씩 블로그 글로 풀어서 공유**하는 시리즈입니다.
다른 중개사 블로그와 가장 크게 차별화되는 콘텐츠라, 블로그의 "간판 시리즈"로 운영합니다.

## 1. 왜 이 시리즈인가

- **남이 못 쓰는 글:** 공공데이터를 직접 가공한 숫자(경기도 상권 순위, 업종별 증감, 점포당 매출)는 다른 블로그에 없습니다. 네이버가 높게 치는 "독창적인 정보"입니다.
- **검색 수요가 분명함:** "서현역 상권", "분당 헬스장 창업", "한식 프랜차이즈 창업" 등 창업자가 실제로 검색하는 말과 정확히 맞습니다.
- **문의로 바로 연결:** 글을 읽은 사람은 이미 그 지역·업종 창업을 고민 중인 사람입니다.

## 2. 시리즈 구성 — 3개 트랙

| 트랙 | 말머리 | 내용 | 노리는 검색어 |
|---|---|---|---|
| 🗺️ **지역편** | `[상권 리포트·지역]` | 역 하나를 잡아 업종 전체 흐름 | ○○역 상권, ○○동 상가 |
| 🏷️ **업종편** | `[상권 리포트·업종]` | 업종 하나를 잡아 분당 어디가 맞는지 | 분당 ○○ 창업, ○○ 입지 |
| 🍔 **프랜차이즈편** | `[상권 리포트·프랜차이즈]` | 프랜차이즈 업종의 브랜드·매출·입지 | ○○ 프랜차이즈 창업, 가맹점 매출 |

- 주 1편, 트랙을 돌아가며: 지역 → 업종 → 프랜차이즈 → 지역 …
- 글 번호를 붙여 쌓이는 느낌을 줍니다: `[상권 리포트 #3]`
- 발행 순서와 원본 리포트 링크: `03_운영/상권리포트_발행목록.md`

## 3. 리포트 → 블로그 글로 바꾸는 원칙

1. **결론 하나로 시작:** 리포트 제목 문장(예: "수내역, 경기도 3위 버거·피자 상권")을 글 제목·첫 문단으로.
2. **숫자는 3~5개만 크게:** 리포트의 핵심 수치 박스를 그대로 가져오고, 나머지 표는 캡처 이미지로.
3. **"추천하는 이유" 카드 → 소제목:** 카드 하나 = 소제목 하나. 짧게 풀어 쓰기.
4. **"함께 살펴보실 점"은 반드시 포함:** 불리한 점을 같이 써야 신뢰가 생깁니다.
5. **현장 사진 2~3장 추가:** 데이터만 있으면 딱딱합니다. 해당 역·거리 사진을 섞으세요.
6. **출처·기준 시점 표기:** 글 끝 "자료 안내"에 출처, 추정치라는 점, 기준 분기를 반드시.

## 4. 리포트에서 블로그로 옮기지 않는 것

- 리포트 안의 **"현장 확인할 곳" 같은 중개사 내부 메모** (특정 점포 폐점 추정 등)
- **특정 지번·의뢰인·건물주 정보** (예: "○○동 158" 같은 물건별 입지 리포트는 주소를 빼고 업종 이야기로 일반화)
- 리포트 전체 표를 통째로 붙여넣기 → 이미지 캡처 2~3장으로 충분

## 5. 문의 전환 장치 — "전체 리포트는 문의 주시면 보내드립니다"

블로그에는 핵심만 쓰고, **전체 리포트 링크는 문의한 분께 문자로** 보냅니다.

```
📊 이 글은 「○○ 상권 리포트」의 요약입니다.
업종별 전체 표, 분기별 추이, 브랜드별 매출 비교가 담긴 전체 리포트가 필요하시면
문자로 "○○ 리포트"라고 남겨주세요. 링크로 바로 보내드립니다.
```

- 장점: 문의 건수 = 관심 고객 명단. 받은 분께 맞는 매물 제안까지 이어갈 수 있습니다.
- 리포트 링크를 보내려면 아티팩트 페이지 공유 메뉴에서 "링크가 있는 모든 사용자"로 공개해 두세요.

## 6. 업데이트 주기

- 추정매출 원자료(경기데이터드림)는 **3개월마다 갱신**됩니다.
- 새 분기 자료가 나오면: 리포트 갱신 → 기존 글 하단에 "○○년 ○분기 업데이트" 추가 또는 새 글 `[상권 리포트 #○] 서현역 2025년 3분기 업데이트`.
- 같은 역을 분기마다 다시 다루면 그 자체가 "분당 상권 기록"이 되어 C-Rank(주제 신뢰도)에 유리합니다.
